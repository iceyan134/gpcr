# v1.0.0 — initial research source snapshot

Initial research source snapshot for ReCAST-GPCR, hosted at https://github.com/iceyan134/gpcr. The release workflow creates the `v1.0.0` tag and GitHub Release from this source commit.

Includes the 88 files delivered in the original `code/` directory, with repository-level documentation and Git ignore rules added. Scientific source files are preserved unchanged.

This release makes source and original recipes inspectable. It does not claim a complete working installation or reproduction of manuscript results. See `docs/REPRODUCIBILITY.md` for missing resources and known limitations.
